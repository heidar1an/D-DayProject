# ۲۷ سپتامبر ۲۰۲۶

## راه‌اندازی گیت/گیت‌هاب برای دو حساب مک

**مسئله:** کاربر روی مک دو حساب دارد (`heidarian` uid 501، `heidarian2` uid 502) و فقط با یکی
می‌توانست pull/push کند.

**ریشه‌یابی (اندازه‌گیری‌شده):**
- ریموت پروژه HTTPS است: `https://github.com/heidar1an/project01.git`.
- `credential.helper=osxkeychain` در `/opt/homebrew/etc/gitconfig` (لایهٔ system، مشترک).
  کیچین `heidarian` رکورد github.com دارد (`acct=198613387`، ۱۰ فوریه ۲۰۲۵) و
  `git credential fill` جواب می‌دهد؛ در کیچین `heidarian2` نیست ⇒ فقط یک حساب کار می‌کرد.
- هیچ‌کدام `~/.ssh` نداشتند.
- `/Users/heidarian/Documents` روی `drwx------` ⇒ `heidarian2` به پروژه دسترسی نداشت.
- گروه مشترک `heidarians` (gid 503) از قبل وجود داشت و هر دو عضو آن‌اند.
- کانفیگ `heidarian2` یک workaround نیم‌بند داشت (helper اپل به‌جای Homebrew) + یک
  `.gitconfig.lock` جامانده.
- پورت ۲۲ گیت‌هاب از این شبکه **باز** است؛ پورت ۴۴۳ هم. HTTPS کند بود (~۱۱.۷s).

**راه‌حل (انتخاب کاربر: SSH، یک کلید جدا برای هر حساب، دو کلون جدا):**
- کلید ed25519 بدون پسورد برای `heidarian` ساخته شد + `~/.ssh/config` + `known_hosts`.
- اثر انگشت میزبان گیت‌هاب با اثر انگشت رسمی مطابقت داده شد
  (ED25519 `SHA256:+DiY3wvvV6TuJJhbpZisF/zLDA0zPMSvHdkr4UvCOqU` ✓).
- اسکریپت مشترک `/Users/Shared/setup-github-ssh.sh` (۳۷۸۴ بایت، ۷۵۵) برای حساب دوم؛
  idempotent، در `HOME=/tmp/testhome` تست شد.
- ریموت **عمداً روی HTTPS ماند**: تا کلید عمومی در گیت‌هاب ثبت نشود، عوض‌کردن ریموت
  کاربر را وسط کار بلاک می‌کند. دستور flip: `ssh -T git@github.com && git remote set-url …`.

**باقی‌مانده:** کاربر باید کلید عمومی `heidarian` و کلید حساب دوم را در
https://github.com/settings/ssh/new ثبت کند (Key type: Authentication Key). بعد ریموت flip شود.
مخزن الان `ahead 1, behind 4` است — merge با کاربر است، خودسرانه انجام نشد.

**دانش قابل‌استفادهٔ مجدد:** اسکیل `macos-multiuser-git-auth` ساخته شد.
