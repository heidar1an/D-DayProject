### باگ ۱ — واژگان سیگنال، گاردهای دست‌نویس را نمی‌دید
`mediaStore.js` گاردش `function fail(message, code = 'VALIDATION_ERROR')` است. رشتهٔ `VALIDATION_ERROR` در **امضای** تابع است، نه در بدنهٔ فراخوانی `fail('متن…')`. سیگنال قدیمی فقط `/VALIDATION_ERROR/` را در بدنه می‌گشت ⇒ هر ۴۹ گارد `fail()` دیده نمی‌شد. همینطور `trim(value, max)` (کمکتابع) با الگوی `.trim()` (متد) و `bool()`/`num()` با `String()`/`Boolean()` فرق داشتند و `.slice(0, max)` بهعنوان گارد طول شمرده نمی‌شد.
**نکتهٔ ظریف:** الگوی سادهٔ `fail(` هم غلط است — `adminApi.js` خودش `fail(code, message)` دارد و `fail('NOT_FOUND', '...')` **پاسخ خطاست نه اعتبارسنجی**. فقط تکآرگومانی `fail('متن')` (سبک mediaStore) یا کد خطای صریحِ اعتبارسنجی سیگنال است.

### باگ ۲ — `functionBody` آکولادِ پارامترِ تخریبی را بدنه میگرفت
`text.indexOf('{', hit.index)` برای `export function replyInboxItem(id, { text, admin = null } = {}) {` اولین `{` را میگرفت که همان **الگوی تخریب پارامتر** است ⇒ «بدنه» میشد `{ text, admin = null }` و هیچ سیگنالی نداشت. **هر تابعی با پارامتر تخریبی کاذب «بدون اعتبارسنجی» میشد**: `approveContent` · `scheduleContent` · `publishContent` · `createMedia` · `setAccountCredentials` · `updateAsset` · `setNotificationState`. رفع با `bodyBraceIndex()` که تا عمق پرانتز صفر نشود آکولاد نمیشمارد.
