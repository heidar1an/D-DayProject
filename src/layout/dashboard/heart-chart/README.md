# نمودار تعداد قلب داشبورد

نمودار تحلیلی قلب‌های کسب‌شدهٔ هر روز، با انتخاب بازهٔ **روزانه / هفتگی / ماهانه / سالانه**.

```
src/layout/dashboard/heart-chart/
├── HeartChart.jsx      ← نمودار SVG (میله، میانگین، تولتیپ، تحلیل دوره) + RangeDropdown در هدر
├── RangeDropdown.jsx   ← دراپ‌داون بازه (listbox با پیمایش کیبورد)
├── heartChart.css      ← استایل + انیمیشن‌ها + گارد prefers-reduced-motion
└── README.md

src/services/hearts/
├── heartSeries.js      ← Pure: تولید دفتر روزانهٔ deterministic + تجمیع بازه‌ها + برچسب‌های جلالی (Intl fa-IR)
└── heartStatsService.js← API + persistence در localStorage (کلید tapesh:hearts:v1)
```

## داده

- دفتر روزانه: `Map<'YYYY-MM-DD', hearts>` برای ~۵ سال جلالی اخیر؛ با seed ثابت تولید می‌شود
  (ریتم دانش‌آموزی: جمعه تقریباً تعطیل، اسپایک چالش/نبرد، روزهای غیبت).
- دادهٔ ذخیره‌شدهٔ کاربر روی seed **merge** می‌شود؛ یعنی روزهای استفادهٔ واقعی همیشه برتری دارند.
- بازه‌ها: روزانه = ۱۴ روز اخیر، هفتگی = ۱۲ هفتهٔ شنبه‌شروع، ماهانه/سالانه = باکت‌های **جلالی**
  (مرز ماه جلالی با میلادی یکی نیست، پس روزبه‌روز گروه می‌شود).

## نکات فنی

- svg با `ResizeObserver` اندازه‌گیری می‌شود (بدون distortion گوشه‌های گرد)؛ ستون‌های hover
  لایهٔ HTML روی svg هستند و در جهت LTR با ترتیب میله‌ها هم‌راستا می‌مانند.
- انیمیشن‌ها: رشد پله‌ای میله‌ها (stagger با `--i`)، ضربان «امروز»، ورود تولتیپ — همگی زیر
  گارد `prefers-reduced-motion` خاموش می‌شوند.
- دراپ‌داون: بستن با کلیک بیرون/Escape، پیمایش با Arrowها، فوکوس اولیه روی گزینهٔ انتخابی.
- هدر داشبورد (استریک/مجموع قلب) فعلاً Mock ثابت است و از این سرویس نمی‌خواند.

## ورود لایه‌های دیگر

هر لایه‌ای که قلب اعطا می‌کند (آزمون، فلش‌کارت، لیگ، ...) فقط:

```js
import { recordHeartGain } from '../../../services/hearts/heartStatsService';

recordHeartGain({ amount: 20, source: 'آزمون تشریح' });
```

نمودار و «امروز» بلافاصله در رفرش/فوکوس بعدی به‌روز می‌خوانند. در نسخهٔ سرور، این فراخوانی به
`POST /api/hearts/gains` با اعتبارسنجی HeartTransaction تبدیل می‌شود.

## تست از کنسول

```js
__heartStatsReset?.(); // در صورت اتصال به window؛ یا دستی: localStorage.removeItem('tapesh:hearts:v1')
```
