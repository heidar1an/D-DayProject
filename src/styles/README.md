# `src/styles/` — پوستهٔ استایل ریشه

`src/styles.css` فقط یک نقطهٔ ورود است: `@import "tailwindcss"` و بعد ۱۶ بخش،
**به همان ترتیبی که قبلاً در یک فایل ۴۷۱۴ خطی بودند**. آبشار CSS دست‌نخورده است.

| فایل | چه چیزی |
| --- | --- |
| `fonts.css` | ده `@font-face` (Doran/Pinar/Vazir + ارقام فارسی) |
| `tokens.css` | `:root` تیره، حالت روشن، استثناهای تم روشن برای کلاس‌های Tailwind |
| `base.css` | `html`/`body`/`.app`/`.app--scroll` |
| `header.css` | سرصفحهٔ سایت، برند، ناوبری، چیپ کاربر |
| `hero.css` | هیرو، نوار پنج دوره، پاپ‌آپ «اول ثبت‌نام کن» |
| `buttons.css` | خانوادهٔ `.button` |
| `benefits.css` | بخش مزیت‌ها |
| `pricing.css` | صفحهٔ تعرفه‌ها |
| `landing-sections.css` | نقل‌قول، بنر رفقا، معرفی تپش |
| `promo-cards.css` | کادرهای تبلیغی محصولات |
| `auth.css` | صفحهٔ ورود/ثبت‌نام |
| `offline.css` | صفحهٔ آفلاین |
| `onboarding.css` | ثبت‌نام تکمیلی |
| `articles-faq.css` | کارت‌های مقاله و سؤالات متداول |
| `footer.css` | فوتر سایت |
| `motion.css` | نوار متحرک، تُن‌های درسنامه، `prefers-reduced-motion` |

## قواعد

- **ترتیب مهم است.** `@import`ها به‌ترتیب در `src/styles.css` می‌آیند؛ جابه‌جایی‌شان
  می‌تواند برندهٔ آبشار را عوض کند. اگر بخش تازه‌ای اضافه می‌کنید، انتهای فهرست
  بگذارید مگر دلیل صریحی داشته باشید.
- **مسیرها یک پله عمیق‌تر شده‌اند.** هر `url()` که قبلاً `../fonts/...` بود، حالا
  `../../fonts/...` است. فایل تازه را با همان قاعده بنویسید.
- رنگ ثابت ننویسید؛ فقط توکن‌های `tokens.css`.
- تقسیم اولیه با بازسازی بایت‌به‌بایت انجام و با `preprocessCSS` ویت تأیید شده است.
